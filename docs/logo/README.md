# Logo

**Idea:** a map tile with the chamfered corner of the app panels; a route ending at a station is cut out of it.

| File | Use |
|---|---|
| `symbol-orange.svg` | default symbol (on dark or light backgrounds) |
| `symbol-black.svg` / `symbol-white.svg` | single color (print, stamps, overlays) |
| `symbol-small.svg`, `favicon.svg` | small sizes ≤ 32 px: wider route, larger ring |
| `app-icon.svg`, `app-icon-maskable.svg` | app icons on anthracite (maskable with an 80 % safe zone) |
| `horizontal-light.svg` | symbol + wordmark for light backgrounds |
| `horizontal-dark-transparent.svg` | for dark backgrounds |
| `horizontal-black.svg` | single color |
| `banner.svg` / `banner.png` | README header |

## Colors
| Name | HEX | RGB |
|---|---|---|
| Orange | `#F59A23` | 245 154 35 |
| Anthracite | `#1B1C1E` | 27 28 30 |
| Light | `#F5F2EA` | 245 242 234 |
| Grey (subline on dark) | `#B8B2A7` | 184 178 167 |

## Rules
- **Clear space:** at least the width of the route on all sides (≈ 11 % of the symbol width).
- **Minimum size:** symbol 16 px (then use `symbol-small`), lockup 120 px wide.
- Do not rotate, distort, recolor (except single-color black/white), add effects or move the route.
- The wordmark is constructed from Barlow Condensed (SIL Open Font License) and is provided as paths.
- Not an official logo of Satisfactory or FICSIT; "Satisfactory" is a trademark of Coffee Stain Studios and is
  used only descriptively.
