# Logo

**Idee:** Eine Kartenkachel mit der abgeschrägten Ecke der App-Panels; ausgestanzt ist eine Route, die an einer Station endet.

| Datei | Verwendung |
|---|---|
| `symbol-orange.svg` | Standard-Symbol (auf dunklem oder hellem Grund) |
| `symbol-black.svg` / `symbol-white.svg` | einfarbig (Druck, Stempel, Overlays) |
| `symbol-small.svg`, `favicon.svg` | Kleingröße ≤ 32 px: breitere Route, größerer Ring |
| `app-icon.svg`, `app-icon-maskable.svg` | App-Icons auf Anthrazit (maskable mit 80-%-Sicherheitszone) |
| `horizontal-light.svg` | Symbol + Wortmarke für helle Hintergründe |
| `horizontal-dark-transparent.svg` | für dunkle Hintergründe |
| `horizontal-black.svg` | einfarbig |
| `banner.svg` / `banner.png` | README-Kopf |

## Regeln
- **Schutzraum:** rundum mindestens die Breite der Route (≈ 11 % der Symbolbreite).
- **Mindestgröße:** Symbol 16 px (dann `symbol-small`), Lockup 120 px breit.
- Nicht drehen, verzerren, umfärben (außer einfarbig Schwarz/Weiß), mit Effekten versehen oder die Route verschieben.
- Die Wortmarke ist aus Barlow Condensed (SIL Open Font License) konstruiert und liegt als Pfade vor.
- Kein offizielles Logo von Satisfactory oder FICSIT; „Satisfactory“ ist eine Marke von Coffee Stain Studios und wird
  nur beschreibend verwendet.
